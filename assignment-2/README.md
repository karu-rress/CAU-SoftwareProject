# Assignment 2: Compare Java and C-style Programs

This assignment compares Java and C-style programs by implementing a program that calculates and manages divisors of natural numbers.

## Results
Test results for the `Divisors` class, which includes methods to find all divisors of a number, count them, check if the number is prime, and find common divisors with another number.

## Usage
Run the following commands to compile and execute the program:
```bash
$ cd java/
$ javac -d out Divisors.java TestDivisors.java # or *.java
```
