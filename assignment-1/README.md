# Assignment 1: Measure Execution Time

Write a program to measure execution time, implement `numCommonDivisor(int i1, int i2)` to find the number of common divisors of two given natural numbers. Then, measure the execution time of that code.

## Requirements
- JDK 21 or higher

## Results
Prints the execution time of the `numCommonDivisor` method in nanoseconds.

## Usage
Run the following commands to compile and execute the program:
```bash
$ javac -d out src/MeasureExecTime.java
$ java -cp out MeasureExecTime
# or
$ java src/MeasureExecTime.java
```
